# Akebulan
Unencumbered Communications For Every Soul on Earth. Give me liberty or give me death, when I can't have one, I'll take the other. We are building a world where distance is no barrier, borders hold no power over connectivity, and all homo sapiens can speak freely.

The project is to develop a website that encourages, complements and supplements Facebook, Twitter and other social media shortcomings. This application is useful for individuals, families and businesses to communicate with encryption and avoid regulations that impede free speech and sell users’ data. The best way to get started is to register. Feel free to use the help tab for more information. The project is maintained via AAA Computer Networking Services, Limited.
